Meet Kura

The PDF standards and preflight engine. Convert any PDF to every PDF/A level, PDF/UA, PDF/X, PDF/E and PDF/VT, then preflight the result against 396 bundled profiles to confirm it conforms.

Ships as a CLI, npm package, browser WebAssembly build, Docker image and C library.

Delivery & licensing model

  • No license key is required or provided. Kura intentionally does not use license keys, to streamline deployment and reduce operational friction.
  • Upon purchase you receive a ZIP archive containing the complete Kura source code.
  • Because Kura is open source, every release and every update can always be downloaded from our GitHub releases page.
  • The source code provided is identical to the code published in our public open-source repository.
  • No refunds. Under no circumstances shall a refund be made after purchase.
